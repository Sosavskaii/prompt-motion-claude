# Le prompt MOTION : fais faire du motion design à Claude

Avec ce prompt, Claude Code fabrique une vidéo animée (typo géante, aplats de couleur, trames de points, particules, objets 3D…) **entièrement en code**, image par image, sans logiciel de montage.

👉 **Le prompt est ici : [PROMPT.md](PROMPT.md)**

## Ce qu'il te faut
- **Claude Code**, avec un abonnement Claude.
- **Node.js** et **ffmpeg** installés sur ton ordi (si tu ne les as pas, demande à Claude Code : « installe Node et ffmpeg »).
- **Une vidéo modèle** : un motion design qui te plaît, téléchargé sur ton ordi.

## Comment l'utiliser (5 étapes)
1. Mets ta vidéo modèle dans un dossier et ouvre Claude Code dans ce dossier.
2. Copie le prompt de [PROMPT.md](PROMPT.md) et remplace tout ce qui est entre [crochets] : ton sujet, ton texte, tes couleurs.
3. Choisis un des 3 storyboards qu'il te propose.
4. Valide les images fixes avant qu'il anime tout.
5. Donne tes corrections comme un réalisateur : « coupe sèche ici », « ralentis ce zoom », « zoome sur le bouton ».

## Le secret : toujours un exemple
Sans vidéo modèle, Claude fait un truc fade : du texte au milieu, un fond en dégradé, tout qui apparaît en fondu. **Avec un modèle, il copie le rythme et le style.** Nommer un style marche mieux que le décrire.

## Bon à savoir
- Les premiers rendus ne sont pas parfaits : compte 2 ou 3 allers-retours de corrections.
- La 3D « chromée » très lisse est le plus dur. Pour aller plus loin, Claude peut passer par Blender.
- N'utilise une vidéo modèle que comme inspiration : ne republie pas le travail d'un autre créateur.
